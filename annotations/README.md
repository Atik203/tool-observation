# Human annotation kit

**Do this yourself.** Do not use an AI assistant to fill the sheets.

**Legend:** 📂 open · ✍️ fill · ✅ done · 🔄 in progress · ⏳ todo · ⚠️ check · 🚫 don't · 📝 example · 💾 save

**Read first:** [how to fill](common/how_to_fill.md) · [glossary](common/glossary.md) · [rules](common/rubrics.md)

## Pick one task

| Task | Items | Time | Start here |
|---|---:|---:|---|
| G0 audit | 40 | 45–60 min | [g0/instructions.md](g0/instructions.md) |
| Severity | 120 | 2–3 h | [severity/instructions.md](severity/instructions.md) |
| Outcome | 160 | 3–4 h | [outcome/instructions.md](outcome/instructions.md) |
| Recovery | 80 | 2–3 h | [recovery/instructions.md](recovery/instructions.md) |
| Verify agent labels | 20 | 45–60 min | [verify/instructions.md](verify/instructions.md) |

Each folder has four files:

- `instructions.md` — what to do
- `packet.csv` — the evidence
- `sheet.csv` — the file you fill
- `example.md` — one worked row

**When done:** 💾 save `sheet.csv` and send it to the project owner. Do not rename it. Do not add columns. Do not edit `packet.csv`.

**Rules for every task**

1. One row per item; keep the `item_id`.
2. No blank answers. If unsure, choose the best label and write `unsure: ...` in `note`.
3. Use only `0`/`1` or the labels shown in the task.
4. Keep notes short (one line).
5. Do not open another rater’s sheet.
6. If a file is missing or a link is broken, stop and tell the project owner.
